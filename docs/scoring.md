# Scoring notes

The score is a shortlist heuristic. It is not presented as the server's exact DPS or survivability formula.

## Profiles

### PvM

Prioritise useful sustained PvM output and enough survivability to keep farming. Offensive stats, attack speed and relevant main stats should normally beat PvP-only value. DD remains useful defensively; REF and SD are not deleted, only de-emphasised.

### PvP

Increase the value of survivability and PvP-specific mechanics. REF and SD-related stats are meaningful here and must not be treated as junk.

### Universal

Compromise between PvM damage/farming and PvP survivability.

### Zen farm

Increase the value of Zen drop while preserving enough combat performance to farm efficiently.

## General comparison rules

- Compare candidates primarily against the item currently occupying the same functional slot/type.
- Do not recommend a nominally higher Gear Score item when its useful weighted value is materially worse.
- Separate `affordable now`, `best value`, and `stretch` candidates.
- A stretch item should justify the missing currency with a meaningful upgrade, not merely a higher asking price.
- Listed market price is not the same thing as a confirmed sale price; future market-history tracking should improve this.

## Known tuning issue

Armor recommendations need continued PvM tuning. Earlier prototypes could over-recommend DD/SD-heavy armor because generic survivability weights overwhelmed build-specific offensive value.
