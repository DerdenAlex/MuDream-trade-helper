# Confirmed project mechanics

These notes record mechanics confirmed during live MuDream testing and should guide scoring and UI decisions.

## DD — Damage Decrease

DD reduces incoming damage. It is useful in both **PvM and PvP**. It must not be treated as a PvP-only option.

## SD — Shield / SD layer

SD is a **PvP-only survivability layer**. In PvP, SD is depleted before direct HP damage. PvM scoring should not award value for SD-related bonuses unless future live testing proves a server-specific PvM interaction.

## Weapon loadouts

A two-handed weapon consumes both hand slots. It must be evaluated against the combined current two-hand loadout, not against only one occupied hand. Dual-wield-capable characters require loadout-aware comparison rather than isolated slot scoring.

## Price semantics

A market price containing multiple jewel types is a compound price: every listed component is required simultaneously.
